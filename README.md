📌 Task 1 – Public API Integration Webpage
📖 Project Title
Random User API – Dynamic Profile Webpage
📝 Description
This project is a responsive web application that dynamically fetches and displays user profile data from a public API (Random User API). The webpage uses JavaScript to retrieve real-time data and presents it in an attractive card-based user interface.
The project demonstrates how to integrate a public API, handle dynamic data loading, and display the information interactively on a webpage.
🎯 Task Objective
Fetch data from a public API
Display the fetched data dynamically on a webpage
Ensure the webpage is responsive and user-friendly
🌐 Public API Used
Random User API
URL: https://randomuser.me/api/
Type: Free, public API (no API key required)
✨ Features
Dynamic data fetching using JavaScript fetch()
Displays:
User profile image
Full name
Age and gender
Email address
Phone number
Location (City, Country)
“Next User” button to load new user data dynamically
Responsive and attractive UI design
Gender-based styling and smooth animations
🛠️ Technologies Used
HTML5 – Structure
CSS3 – Styling & responsiveness
JavaScript (ES6) – API integration and dynamic content
